优化要点：
  • 文件夹信息卡片化 — 蓝色渐变背景 + 大图标 + 权限徽章，一眼看清自己的身份
  • 权限用图标 + 颜色区分 — 只读=灰色👁、可写=蓝色✏、管理=绿色⚙，比纯文字标签更直观
  • 权限用分段切换器 — 比 el-select 下拉更快，少一次点击
  • 成员列表用头像 + 信息卡 — 比 el-table 更友好，像 IM 工具的群成员管理
  • 移除 Tabs 切换 — 添加 + 列表 + 转让在同一屏，不用切来切去（转让可折叠在底部）
  • 空状态加图标和引导文案 — 比纯文字「还没有分享给任何人」更有温度
