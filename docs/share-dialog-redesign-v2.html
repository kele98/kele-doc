设计要点：
  • 配色契合 — 严格用主题色 #1ea59a（青绿）做主色调，文件夹信息卡片用主题浅色背景，告别之前 mockup 用的 Element 默认蓝
  • 移除 Tabs — 添加 + 列表 + 转让三块在同一屏纵向排列，不用切来切去，符合 kele-doc 其他页面的扁平化风格
  • 联合搜索 — 一个搜索框同时搜用户和群组，下拉按分组标题（用户/群组）区分，解决"群组怎么添加"的问题
  • 权限徽章 + 下拉（替代分段切换器） — 紧凑单选按钮，色点 + 文字 + 箭头组成触发器，颜色随权限变化（灰/青/绿）。下拉每个选项附一行说明，让用户清楚每个权限的实际影响，首次使用零学习成本
  • 成员列表用头像 + 信息 — 用户头像用主题色渐变，群组头像用文件夹色渐变，视觉上就能区分类型
  • 权限徽章带语义 — 只读=灰、可写=主题色、管理=绿色（成功色），所有者=主题色描边徽章
  • 转让所有权折叠 — 默认折叠在底部虚线分隔下，避免用户误操作，展开后红色警示 + 二次确认
  • 权限隔离 — 只读用户看到的添加区禁用、不显示转让入口，但能查看成员列表（含权限分配）
  • 空状态优化 — 主题浅色圆形图标 + 引导文案，比纯文字"还没有分享给任何人"更有引导性
